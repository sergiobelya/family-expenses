# Documentation Guidelines

- Keep documentation as concise as possible and use plain language.
- Do not duplicate requirements, rules, or logic. Choose the most appropriate section for each rule and keep its full description there.
- When another section needs to refer to a rule, a brief cross-reference is usually enough. Do not repeat the rule itself; use cross-references sparingly too.
- Remove outdated discussions, intermediate alternatives, and decisions superseded by final ones. Keep current rules and unresolved questions only when they are needed for further work.
